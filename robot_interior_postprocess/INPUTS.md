# 更换机器人和电路的当前支持范围

新增载板装配入口的输入边界另见 [载板装配工作流](CARRIER_ASSEMBLY_WORKFLOW.md)：它支持原 anything2robot 机械输入及规范化机械/电气适配器，按配置将载板分配到不同 link。下表仍描述原 `run.py` 的历史接口，不能将其仙人掌电路替换规则视为通用导入器。

几何、候选布局和路由算法可以复用；当前输入适配器仍按仙人掌实例实现，不能保证任意外壳与电路直接导入就成功。

| 输入变化 | 目前需要做什么 |
| --- | --- |
| 同格式 Anything2robot 输出 | 位姿和关节信息直接读取 `robot_result.pkl`，装配变换读取制造 CSV，无需手工填写坐标。配置指定 `design_result`、`manufacturing_result`；电路与机械使用不同 ID 时通过 `motor_mapping` 关联。 |
| 单独 STL/STEP 外壳、已有空壳 | 当前入口不支持直接使用；要增加装配坐标、材料/空腔识别和关节/电机位姿导入。现有适配器有意拒绝多边界空壳，以免误填已有空腔。 |
| 新电路 | 目前读取单组 Eagle `.sch`、`.brd`、指定格式 `bom.csv`，并核对三者。`circuit.py` 的 P1 电源替换、U1 供电及端口分配仍与本例绑定，必须适配新元件和网络。 |
| 新元件 | `components` 配置给尺寸与安装余量；还需更新端口定义、数量、电气接口与机械电机映射。仅有 BOM 名称或 STEP 模型不足以推导接线端口。 |
| 安装位置变化 | `placement_part` 当前将所有可移动电子模块安排在一个部件。新的机器人需要选择可用部件；多舱自由分配仍需扩展。 |

电机禁入包络始终固定在机械输出的位置。余下元件只在实际生成的内腔减去材料、安装支撑、电机包络及余量后搜索位置。换机器人的空间不足时会失败或输出 partial，不保证每个机器人都能容纳同一套元件。

新配置应使用新的 `output` 目录，避免覆盖仙人掌结果。修改机械输入、壁厚或禁入参数后必须重建几何，不能强制复用旧缓存。最终 `concept_complete` 表示当前静态概念模型满足已实现的检查；实物接口、电流、装入路径、关节运动和制造仍需验证。
