# 通用可拆壳体与装配切分算法设计

状态：部分实现，尚未完成端到端可打印版本。当前 04 版本 17 的 124 项通过结果仍属于旧算法，不证明本文约束已经满足。用户已要求同步推进 Pico 2、接线及 PLA / 0.4 mm 喷嘴打印候选。

## 2026-11-16 方法修正与文献依据

用户要求的是每个装配部件的分型线，不是对单个示例反复修补局部检修盖。目标流程调整为：建议分型面 → 登记完整关节安装面的禁切区域 → 确定主壳/盖归属 → 在所属壳件生成载板和连接筋 → 生成闭合紧固接口 → 检查装配并导出。切缝必须成为支撑结构生成的上游输入；不能先把所有筋固化，再无限搜索剩余表面的可拆盖。

依据及适用范围：

- [Interactive Partitioning of 3D Models into Printable Parts, 2018](https://research.tudelft.nl/en/publications/interactive-partitioning-of-3d-models-into-printable-parts/)：禁切区域、切平面指定及组件合并可避免 BSP 穷举。其目标是打印分块；电机接口、工具空间与可拆盖约束是本系统在此基础上的工程扩展，并非论文已验证的能力。
- [Chopper, 2012](https://gfx.cs.princeton.edu/pubs/Luo_2012_CPM/)：模型分块的研究基线。今晚不采用大规模组合搜索作为默认路径。
- [Protolabs Network 外壳设计指南](https://www.hubs.com/knowledge-base/enclosure-design-3d-printing-step-step-guide/)：可拆外壳的连接、定位与紧固设计参考；具体尺寸仍按实际硬件和打印参数生成。

已落地：VLM 提示从局部检修孔改为整件分型面建议；几何候选现在实际使用建议点（此前忽略了 center_mm），并生成完整安装面之后的偏置平面。新增平移不变性、禁切接口偏置和过薄壳体测试。VLM 未调用时仍明确标记本地建议。

新增实现（端到端验证进行中）：graph_assembly 的实际切分已移到安装座连接筋生成之前，主流程不再调用后置多盖搜索。舵机安装座与舵盘连接座的位置不变，以完整包络作为切缝保护区；支撑连接先尝试所属主壳上的真实最近表面点，失败时再尝试有界替代路径，盖子不能成为连接筋穿越的材料。全部支撑生成后重新验证装配路径与盖子的连续拆卸路径。未生成的安装座不再被错误要求已包含在源壳体内。新增独立几何测试验证固定安装座、最近表面连接以及盖子避让。

04 已生成版本 18 的独立空壳切分结果（8 个壳件、12/12 阶段检查）。尚未完成：新的完整装配、Pico 2 布局、排线与完整机器人打印包。上述内容不能描述为已生成或已验证。完整装配路径当前优先把舵机安装座保留在主壳；允许安装座分属多个可拆壳件并分别安装硬件，需要进一步扩展装配状态，目前不宣称支持。

用户已确认的下一步配置：3 个 SG90、Pico 2（明天焊接排针，方向待实际确定）、电池盒（尚未购买，外形和电池配置未确定）；PLA、0.4 mm 喷嘴。电子元件支架在切分后安排，优先平行切分面，仍须给接头和线缆留空间。用户曾提出 Waveshare Bus Servo Adapter (A)，经[官方规格](https://www.waveshare.com/product/bus-servo-adapter-a.htm)核对其用于 ST/SC 串行总线舵机，用户已确认继续使用 SG90 并调整驱动方案，因此不将该板作为已兼容部件生成支架或确定采购项。

## 1. 目标与边界

将每个运动刚体划分为可制造、可装配、可再次拆卸的打印零件。装配时打开壳体，完成电机、舵盘、压板与螺丝操作，再闭合壳体。默认禁止为了电机装入或螺丝刀路径在最终外观上留下永久工具孔。

这里的打印零件切分不改变关节图：同一刚体的多个壳件闭合后仍是一个刚体。输出轴基准、关节位置与真实硬件尺寸不变。不得根据模型名称、项目 ID、左右臂标签或固定坐标选择切法。

允许的最终开口必须分类登记：关节输出轴与必要运动间隙、配置中明确需要的接口或通风口、闭合接缝、壳体连接紧固件的孔。最后一类须有真实紧固件和安装面，不能把任意工具通道改名为螺丝孔。运动避让若需要大面积缺口，应报告外观冲突并重新规划，不能自动豁免。

## 2. VLM 与几何求解的职责

采用 VLM 辅助，但几何可行性不能依赖 VLM 判断。

VLM 输入：带稳定表面区域编号的多视角渲染、刚体与关节图、安装面和承力区叠加、候选拆分预览。输出：适合隐藏接缝的表面区域、需要保持完整的外观区域、建议开启方向与理由，可返回多个排序建议。引用表面区域 ID，避免直接猜测三维坐标；重网格化后旧区域引用失效并重新生成。

VLM 不输出最终切割网格，不决定孔径、壁厚或螺丝规格，不宣称无碰撞。它的建议作为可选的外观排序依据；用户明确的保留区域为硬约束。保留来源、模型与输入摘要、置信信息；置信信息不作为安全保证。

VLM 不可用或建议无效时，几何求解仍按曲率、可达性、局部主轴和表面面积生成候选，并标注“未进行语义外观评估”。候选必须通过相同的装配检查，不以模型建议替代证据。

## 3. 输入与保护区域

输入包含未被装配通道切穿的壳体、内部安装结构、真实硬件与公差、各连接接口、零件归属、装配操作、打印工艺参数、关节运动范围和外观约束。不能从已经挖孔的最终 STL 简单补洞，必须从通道切割前的上游几何重新生成。

为每个受力接口建立不可切分的保护组：

- 完整安装接触面，包括安装耳承托面或输出连接面。
- 螺丝座、螺母座、孔周必要材料和装配公差范围。
- 安装座至外壳的连续连接筋及其在壳壁上的落脚区。
- 参数化的边缘余量；数值来自材料、壁厚、紧固件和工艺配置，缺少强度依据则标记待实物验证。

每个保护组必须整体属于一个打印零件，不能只保护几何表面而切断背后的承力连接。同一刚体中有相交的保护组则合并；互不相交的组可以归属不同壳件，但不能凭空假定壳件连接具备足够刚度。首版优先将主要安装组留在同一承力主壳上。

手臂等末端刚体即使只有输出连接件，也必须检查连接螺丝与舵盘中心螺丝的操作，不能以“没有内部电机”为理由跳过拆分需求。

## 4. 候选切分

先尝试无额外拆分：只有全部装配操作可在已声明的装配状态中完成，且不需新增永久工具孔时才接受。

需要拆分时，从简单到复杂生成有限候选：

1. 建议平面切分：优先使用 VLM / 用户指定的分型点和方向，默认将装配部件拆为主壳与壳盖。
2. 偏置平面切分：避开完整安装面，沿局部主轴和表面法向生成少量方向与偏移，允许两部分明显不等大。
3. 绕开保护区的阶梯或折线分界：对接近可行的平面候选，在保护区附近绕行，让完整关节连接端留在主壳的一侧。
4. 有限数量的多片壳体：仅在两件方案失败时扩展，零件数量受配置预算约束。

所有方向由输入几何、接口坐标系和语义区域推导。所谓“手臂根部完整保留”是保护输出接口组后的结果，不是专门为手臂写的规则。

非平面分界可在壳体体素邻接图上求解：主壳保护组作为固定标签，候选可拆面作为另一标签；切割代价包含接缝长度、曲率、外观区域和薄弱区域惩罚。输出标签边界需重建为闭合、无自交的切割体，之后用精确实体运算生成零件。体素结果只用于提案，不能直接视为制造几何通过。

不可仅靠任意曲面最小割决定最终切缝，否则可能生成互相卡住的壳件。每个候选必须附带一个明确的脱离方向，再检验其运动路径。首版只支持沿单一方向直线拆卸；不满足时换切法，不能假装可自由穿出。旋转或多段路径留作后续能力。

## 5. 壳件闭合接口

为候选接缝生成参数化定位边、搭接或止口及紧固座，包含打印间隙、最小边距和壁厚约束。新增结构不得侵入电机、舵盘、关节运动或工具路径。

优先采用可反复拆装的螺丝接口。螺丝与螺母必须来自配置中的硬件规格，具有真实尺寸、工具路径、数量和装配顺序；缺少长度或螺纹方案则不能标记为制造就绪。不要默认为未知打印材料生成可靠卡扣。

闭合件的最后几颗螺丝必须从外部可拧紧并可再次松开。不能出现“要打开盖子才能拧上这个盖子的固定螺丝”的循环。壳体螺丝的小孔允许登记为紧固接口；不允许以此掩盖电机大小的永久装入孔。

## 6. 装配状态与路径联合求解

建立显式装配状态：每个打印零件和硬件均为未安装、已安装或已拆下之一。每个操作记录所需状态、安装目标、运动路径、工具与紧固件路径、结束状态和前置依赖。

操作类型包括壳件开启/闭合、电机装入、螺母预装、舵盘连接、子刚体连接和螺丝紧固。不是所有盖板都必须最后一起关闭：先后关系由真实可达性决定。

路径检查只可排除该状态明确未安装或已拆下的零件；所有已存在的壳体、连接筋、硬件和邻近刚体都参与碰撞。装入件从外部到安装位的扫掠、螺丝与工具的进入退出、盖板闭合和再次拆卸都要检查，保留公差与端点贴合关系。

依赖图无环只是必要条件，还要逐步执行状态检查，确认每一步都可达、所有承诺后装的零件最终装上。需要先转动关节才能安装时，必须显式给出关节姿态并检查允许范围和运动碰撞；首版无法验证则拒绝该候选。

## 7. 硬约束与候选排序

硬约束失败直接淘汰，不能通过外观评分抵消：

- 所有安装保护组完整归属，承力连接连续，输出基准不漂移。
- 每个打印零件是有效实体；无未登记碎片、不可打印薄片或自交。验证最小壁厚、紧固边距与配置要求。
- 所有装配、闭合和指定检修步骤存在且可达；依赖无循环。
- 闭合态不存在未登记的永久装配孔，关节运动与硬件无冲突。
- 所有生成的壳体紧固件落实到接口、预览、导出、BOM 和验证状态。

在可行候选中按明确优先级排序：较少壳件与紧固件 → 较简单的装配/拆卸路径 → 较少显著接缝 → 较低打印难度与材料成本。接缝偏好可配置；不能让 VLM 的外观评分压过硬约束。

使用有界候选数与时间预算；每轮保留失败原因和最好候选。无解时报告冲突，例如“保留完整安装端后，剩余开口不足以装入指定电机”。不自动退回永久挖孔、不缩小硬件、不移动关节或删除原模型附肢。

## 8. 主流程与现有实现接入

流程：

```text
恢复装配通道切割前的壳体与完整安装结构
→ 建立接口保护组和装配任务
→ 生成表面区域及 VLM 外观建议
→ 搜索候选切分和脱离方向
→ 生成闭合定位与紧固结构
→ 联合求解装配状态、顺序与全部路径
→ 检查闭合态外观开口、运动与打印几何
→ 排序并输出可拆零件、装配说明与证据
```

现有接入点：

- `shell_access.suggest`：从“一个椭圆盖位置”扩展为多个表面区域和语义偏好；沿用严格输出契约验证。
- `shell_access.access_requirement`：改为基于未完成的装配/检修任务判断，取消外部模块或输出末端可以默认用工具孔解决的分支。
- `shell_access.local_panel`：保留为候选生成器之一，新增偏置切分与保护区绕行候选，不能仅扩大椭圆口。
- `graph_assembly`：电机装入扫掠和工具扫掠先作为状态中的可达性约束，不直接从永久外壳扣除。仅明确的功能开口和紧固孔进入最终切割。
- `fastening`：扩展已有装配依赖到打印壳件状态，复用真实紧固接口检查。
- 预览与导出：提供闭合、拆开、按步骤装配三种显示；拆开视图的位移来自已验证路径。高亮安装保护组与主壳归属，输出独立打印文件和统一零件 ID。

新增设计结果建议分为 `shell_parts`、`protected_interface_groups`、`split_interfaces`、`assembly_states`、`assembly_operations`、`permanent_openings`、`validation`。路径、切缝与安装面引用同一版本几何；不能混用历史版本的通过证据。

## 9. 给下一阶段电子布局的接口

结构阶段输出每个刚体的闭合态可用内部空间，并扣除电机及运动包络、连接筋、止口、螺丝柱和必需通道；同时提供每个装配状态下可访问的空间、可安装表面、检修入口和拆卸方向。壳件须有独立 ID，电子器件可归属于主壳或可拆盖，不能仅记录所属刚体。

电子布局除静态放得下，还需校验器件装入、固定、插拔与电池更换路径。若器件固定在盖板上，须检查连线余量、接插件断开顺序和开盖扫掠。器件、电池或连接器选型未知时，只能输出候选空间，不能宣称已经满足它们的安装要求。

电子布局产生新的 `service_opening_requirements` 等需求后，允许触发有界的切分重规划；重规划使受影响的装配、排线和导出证据失效，重新验证后再发布。切分先为机械装配生成可行初案，不承诺在电子配置确定前最终冻结。

## 10. 验收与实施阶段

第一阶段：状态化可达性、永久工具孔禁止规则、平面/局部盖候选、接口保护组、闭合紧固和完整路径检查。

第二阶段：保护区绕行的非平面候选与有限多片搜索。必须经过这一阶段，才能覆盖无法以简单平面保留完整安装端的输入。

第三阶段：预览/导出/装配说明与电子布局空间契约，随后进入电子元件实际排布。

验收输入至少包含：偏心输出的方形舵机、圆形执行器、只有输出连接的末端壳体、弯曲细长壳体、多个安装面争用空间的壳体，以及明确无解的窄小输入。不同尺寸和旋转后的同一模型应保持硬件尺寸与接口语义一致。04 只是回归案例之一。

关键反例：切缝绕过安装面却切断连接筋；零件闭合有效但无法拆出；最后一颗盖板螺丝被遮挡；舵盘螺丝需工具孔才能拧；VLM 给出无效区域；未知电子器件被错误宣称可装入。这些必须失败或触发重新搜索。

闭合外观检查比较批准的目标外表面与闭合壳件联合表面，在明确公差下检查未授权缺口及额外突出；只允许登记的接缝/功能接口偏差。不能只验证“实体连通”来代替外观闭合。

软件验收仍不等于物理承载认证。安装面、切缝配合、打印强度、螺丝实际规格和舵机负载须独立试装或测试；应先打印代表性接口试件再评估整机制造。
