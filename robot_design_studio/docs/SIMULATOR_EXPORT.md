# 仿真模型导出

用户于 2026-11-15 明确取消控制程序生成和仿真验证。系统保留 URDF/MJCF 导出，不启动物理引擎、不生成运动轨迹、控制固件或串口程序。这一决定覆盖原完整 Prompt 中相冲突的要求。

## 使用

完成第 05 步内部电子装配后，在第 07 步点击“导出 URDF / MJCF 模型包”。解压 `simulation-model.zip`，保持 `robot.urdf`、`robot.xml` 和所有 `sim-*.stl` 在同一目录。在目标仿真软件中选择相应格式。项目完整审阅包的 `simulation/` 目录也保存这组资源。

导出直接使用当前派生装配的壳体、连接件、电机包络和电子托盘，核对来源摘要及项目版本。模型中的长度为米、质量为千克、角度为弧度。刚体坐标原点位于输入关节位置，网格转换到对应局部坐标；关节父子关系、轴向、范围来自已保存的关节图。

## 工程假设

质量和惯量按实际导出实体体积及显式密度假设计算，默认打印件 1200 kg/m³、硬件包络 1000 kg/m³，可在界面调整。这些值不是实测材料/硬件数据；真实质量保留 null。默认每关节 1 N·m 为导出占位参数，不代表所选电机真实能力。MJCF 的增益、阻尼以及 URDF 速度限制亦为占位假设，使用者可在目标软件中配置。

当前导出采用固定底座。MJCF 禁用接触，URDF 不生成未经核实的凸碰撞代理；需要接触仿真时应在目标软件中配置。这不影响交付关节树、外观网格和惯量定义，但不代表接触或动力学经过验证。

## 软件检查与历史

仅做静态 XML、相对网格资源、刚体/关节集合、坐标和轴向定义检查。结果使用 `export_valid`，并明确 `simulation_performed:false`。不将“文件可交付”表达为“仿真通过”。无需 MuJoCo 安装，任务复用已有几何 Python 环境。

最新范围调整前的仿真运行证据及独立环境保留于原位置，作为历史记录；不再从正式入口运行。旧项目可直接生成新的模型包，旧仿真结果不会自动混入新交付包。
