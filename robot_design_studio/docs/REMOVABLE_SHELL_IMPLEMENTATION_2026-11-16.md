## 完整装配路径与底层规则

## 已接入的规则

- 电机装入和螺丝工具扫掠作为开壳状态约束，不再直接从最终外壳扣除。
- 输出连接面、安装耳座和完整连接筋保留在承力主壳中；搜索偏置平面、保护区阶梯和局部装配区域绕行。
- 在原壳体材料内避开装配通道寻找连接带，让多个安装座与后续盖板固定座保持连通；连接带仅保留现有材料，不添加模型专属补件。这不代表已验证连接带的强度。
- 将模板原有的有界螺孔、槽孔单独登记并保留，避免连接座并入外壳时被原材料填回。它们与长距离工具扫掠分开处理，不以功能孔为理由贯穿对侧外壳。
- 两件方案失败后，按实际外部装入方向分组，搜索最多六个可拆壳件。每个壳件有独立打印文件、螺丝座、装配记录和展开方向。
- 先做姿态碰撞排除，再对接受的方案检查完整连续拆卸扫掠。采样通过本身不能算作拆卸通过。
- 每颗盖板螺丝都检查承压面、螺母预装入口、外部工具路径以及钻孔后的两侧连通性。螺丝型号/实际长度与打印配合仍需核实，制造就绪保持 false。
- 检查原壳体材料在闭合后是否恢复，仅允许登记的接缝和紧固孔；无解时返回失败，不退回永久工具孔。

## 装配状态

盖板螺母先预装。每个身体部件完成自身电机固定和上一级输出连接后闭合，再连接下一级身体部件。输出连接螺丝必须在上一级壳体已闭合时仍然可达。

盖板拆卸检查允许尚未连接的下级身体部件缺席，但保留已连接的上级壳体与硬件。该状态同时写入闭合螺丝报告和装配依赖，不是仅在碰撞检查中隐藏部件。拆修按逆序进行；软件路径检查不等于已经实物试装。

## 实现位置

- `studio/mechanics/assembly_split.py`：候选切分、接口保护、紧固座、连续拆卸、有限多盖搜索。
- `studio/mechanics/graph_assembly.py`：取消永久装配孔、原始腔体残屑记录、壳件状态与装配顺序、独立导出和布局接口。
- `studio/mechanics/fastening.py`：上级闭合后的输出螺丝可达性。
- `studio/mechanics/cover_fasteners.py`：按壳件 ID 和声明的装配阶段验证闭合紧固接口。
- `web/viewer.js`：沿生成结果登记的真实拆卸方向显示展开视图。

VLM 给出分型面建议，几何求解负责实际切割。本轮用户明确授权后已调用配置的在线 VLM；正式生成接口接收其建议，记录为 provided_parting_regions，不虚构生成任务再次调用了在线模型。空壳验证和完整装配验证分别记录。

## 下一阶段边界

新增 `shell_assembly_interfaces` 返回承力主壳、可拆壳件 ID、开启方向和路径长度，并明确电子安装尚未验证。电子元件选型/排布后需要重新检查装入、插拔、电池更换及开盖线缆余量，不能用本次机械结果替代这些验证。

保护区使用保守包络，有限方向与直线拆卸搜索可能拒绝实际上需要更复杂运动或不同安装姿态的输入。拒绝是搜索能力边界，不表示物理上绝对无解。未实现自由曲面任意多段运动、材料强度认证或自动硬件采购定型。
